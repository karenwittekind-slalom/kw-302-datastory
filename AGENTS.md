# AGENTS

This project is a fictional interactive data story for Bean & Bloom Organic Chocolate. The core insight is that improving yield from 89% to 93% creates the strongest combined return across service, cost, waste, resilience, and carbon.

- Data and shared calculations live in `src/data` and `src/utils`.
- Keep all metrics internally consistent. Shared values must reconcile with the yield model and story narrative.
- Do not add a backend, API keys, paid services, or runtime AI.
- Preserve accessibility, keyboard support, and reduced-motion behavior.
- `npm run build` must pass before work is considered complete.
- Avoid unnecessary dependencies. Favor small, clear, reusable components.
- Keep explanations brief and focused on the operating decision.
